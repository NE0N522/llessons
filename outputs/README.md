# Код по полочкам — HTML и CSS

Учебный курс для начинающих и преподавателей. Для чтения уроков сборка и установка не нужны: открой `index.html` в браузере. Кабинет, вход по паролю, задания и хранение работ требуют запуска серверной версии; инструкции находятся в [руководстве проекта](../README.md).

## Как устроена программа

В курсе 11 уроков в трёх блоках: HTML и содержание, CSS и раскладка, практические сайты. Темы сверены с примерами из ZIP: каркас HTML, семантика, таблицы, основы CSS, display и position, Flexbox, базовый Grid, наведение и переходы, БЭМ, Bootstrap, сайт отеля, страница приложения и итоговая страница. Повторяющиеся объяснения объединены, а самостоятельные уроки про аудио и видео, сложные формы, продвинутые селекторы, keyframes, Git и публикацию убраны из основного маршрута.

В каждом шаге остаются два наглядных примера с отдельными переключателями. Код редактируется в локально собранном CodeMirror 6 с подсветкой, номерами строк, Emmet и мягкой проверкой типичных ошибок; предпросмотр работает в изолированном iframe. Размер шрифта можно менять и сохранять в профиле ученика. У каждой карточки указаны цель и ключевые теги или свойства. Для каждого урока есть два полных проектных образца на отдельной странице с полноэкранным предпросмотром, переключением HTML/CSS, нумерацией и копированием кода.

В трёх проектных практикумах есть этапы с контрольными точками, стартовые материалы, образец результата, критерии, подсказки и эталон для преподавателя. План занятия и ответы открываются в сворачиваемой панели.

## Прогресс и оформление

Для посетителя без входа отметки о прохождении и последний открытый урок сохраняются в `localStorage` этого браузера. Ученик, вошедший в серверный кабинет, синхронизирует отметки шагов и прохождение уроков с профилем. Если браузер блокирует хранилище, курс продолжает работать, но локальные отметки не сохраняются.

Сайт при первом открытии учитывает системную тёмную тему. Кнопка в шапке переключает оформление вручную, выбор запоминается. В редакторах уроков при открытии показывается HTML; CSS появляется при выборе своей вкладки. Нажми Esc, затем Tab, чтобы выйти из редактора клавиатурой. Навигация кабинета появляется только на сервере; запуск через `file://` оставляет курс доступным и не включает авторизацию.

Для кабинетов действует та же сохранённая тема, а страницы входа и первой настройки имеют собственную кнопку переключения. На мобильном экране кабинеты показывают нижнюю навигацию и строки таблиц как карточки. Внутренний каталог общих компонентов доступен разработчику по `/ui-kit.html` только в режиме разработки сервера; production маршрут намеренно скрыт.

## Проверка и справочник

- `check.html` — локальная страница проверки структуры активных уроков.
- `reference.html` — краткие заметки только по темам, которые встречаются в программе. Записи отсортированы по числу уроков, в которых используется тема.
- `docs/ОТЧЁТ-приёмки.md` — карта сокращённой программы и её связь с исходным ZIP.
- `docs/lesson-template.js` — шаблон данных урока для дальнейшего расширения.

## Файлы

- `index.html` — главная программа и прогресс.
- `lesson-view.html?lesson=ID` — страница урока.
- `examples/view.html?lesson=ID&project=0` — отдельная страница проектного образца.
- `reference.html` — справочник.
- `check.html` — локальная проверка структуры.
- `assets/course.js` — порядок уроков, блоки, цели и темы карточек.
- `assets/lessons/lesson-ID.js` — содержание активного урока.
- `assets/app/` — оформление, форматирование и логика страниц.
- `assets/vendor/code-editor.js` — собранный офлайн-редактор; исходники и команда сборки описаны в [`docs/РЕДАКТОР-КОДА.md`](../docs/РЕДАКТОР-КОДА.md).
- `assets/vendor/bootstrap.min.css` — локальный Bootstrap 5.3.8 для учебных примеров; пересобирается командой `npm run build:vendor`.
- `assets/app/accounts/stage6.css` — стили аналитики класса и мастера завершения года.
- `assets/fonts/NotoSans.ttf` и `assets/fonts/OFL.txt` — локальный кириллический шрифт для PDF-отчётов; условия и источник указаны рядом в `assets/fonts/README.md`.

## Совместимость

Уроки работают как статический сайт; готовые файлы редактора и Bootstrap уже включены в репозиторий. В песочницах скрипты внутри образцов отключены: предпросмотр показывает HTML и CSS, но не запускает JavaScript. Ученические работы отправляются только на серверную версию сайта; их код открывается в изолированном предпросмотре с отключёнными скриптами и внешними запросами.
