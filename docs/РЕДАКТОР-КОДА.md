# Редактор кода для курса и кабинетов

Редактор собран локально из CodeMirror 6 и Emmet. Сайт использует готовый файл `outputs/assets/vendor/code-editor.js`; он уже включён в репозиторий и не требует сборки при запуске на Render. Страница подгружает его только тогда, когда на ней действительно появляется редактор. Запросов к CDN и сторонним сервисам нет.

## Исходники и сборка

- `editor-src/main.js` — CodeMirror, клавиши, подсказки, мягкая проверка, тема и размер шрифта.
- `editor-src/css-properties.json` — локальный список известных CSS-свойств.
- `editor-src/THIRD-PARTY-NOTICES.md` — лицензия списка CSS-свойств.
- `outputs/assets/vendor/code-editor.js` — минифицированная сборка, около 634 КБ без сжатия.
- `outputs/assets/vendor/bootstrap.min.css` — локальная таблица Bootstrap 5.3.8 для урока и предпросмотров, чтобы они не обращались к CDN.
- `scripts/build-course-vendor.js` и `npm run build:vendor` — пересборка локальной копии Bootstrap и файла лицензии из dev-зависимости.

Чтобы изменить редактор и пересобрать готовый файл, выполни:

```powershell
npm run build:editor
npm run build:vendor
```

Для сборки используются dev-зависимости `codemirror`, языковые пакеты HTML/CSS, `@emmetio/codemirror6-plugin` и `esbuild`. В опубликованной версии редактора их отдельные файлы не загружаются.

## Возможности

- Подсветка HTML/CSS, номера строк, автоматические отступы, подсветка парных скобок, история изменений и видимое клавиатурное управление.
- Автозакрытие HTML-тегов и парных скобок, автодополнение тегов, атрибутов, свойств и распространённых значений CSS. Атрибуты `class`, `id`, `href`, `src` и другие вставляются в форме `имя=""` с курсором внутри кавычек; логические атрибуты вроде `disabled` остаются без значения.
- Выбранную подсказку можно принять клавишей `Tab`, `Enter` или щелчком по пункту меню. После принятия `Tab` снова раскрывает Emmet или добавляет отступ, а `Enter` переносит строку. CSS-свойство вставляется как `свойство: ` и оставляет курсор перед значением; распространённые значения тоже доступны в списке.
- Emmet: HTML5-каркас, `div.card>h2+p`, `ul>li*3`, `img`, `a`, `table`; короткие CSS-записи `df` и `m10`.
- Enter между парными тегами создаёт внутреннюю строку с отступом. `Ctrl+/` включает комментарий HTML или CSS. `Esc`, затем `Tab` переводит фокус из редактора.
- Мягкая волнистая подсветка незакрытых и лишних HTML-тегов, `img` без `alt` и неизвестных CSS-свойств. Она только подсказывает и не блокирует работу.
- Кнопки форматирования HTML/CSS используют локальный форматтер курса; `Ctrl+Z` отменяет форматирование. Перед сбросом к стартовому коду текущая версия сохраняется в истории, откуда её можно вернуть.
- Размер текста задаётся от 12 до 24 px. Для вошедшего ученика значение хранится в `user_settings`; локальное хранилище браузера работает как запасной вариант.
- Учитель может отключить подсказки в параметрах задания. Подсветка, номера строк и отступы остаются; автодополнение, Emmet, автозакрытие и мягкая проверка отключаются.
- В проверке работы учитель видит HTML/CSS в режиме только для чтения с отдельными номерами строк.

## Где используется

Песочницы курса собираются общей функцией из `outputs/assets/app/playground.js`. Поэтому один компонент заменяет редактор во всех шагах активных уроков и практикумов, которые объявлены в `outputs/assets/lessons/`. В кабинете ученика редакторы создаёт `outputs/assets/app/accounts/assignment.js`, а read-only режим проверки — `outputs/assets/app/accounts/teacher.js`.

## Проверка

`npm test` запускает API-проверки и Chromium-сценарии с вводом через клавиатуру в настоящем CodeMirror. Сценарий проверяет Emmet HTML и CSS, режим без подсказок, серверное сохранение шрифта, форматирование и отмену, снимок перед сбросом, восстановление версии, изоляцию предпросмотра и read-only редактор с нумерацией строк. Отчёт текущей проверки браузерных размеров и снимки находятся в `report/stage-3/`.
