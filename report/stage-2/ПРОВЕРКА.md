# Этап 2 — кабинеты, единая тема и доступность

## Результат

Кабинеты учителя и ученика, вход, первая настройка и смена пароля используют общую синюю палитру курса и поддерживают светлую и тёмную темы. На узком экране появляется нижняя навигация, таблицы становятся карточками, основные элементы управления имеют удобную для касания высоту.

### Дефекты: было → стало

| До | После | Проверка |
| --- | --- | --- |
| В кабинетах встречались зелёные акценты и разные оттенки поверхностей. | Стили используют общие переменные `theme.css`, связанные с палитрой курса; для ошибки и предупреждения оставлены смысловые цвета. | Скриншоты light/dark, axe-core, проверка CSS на цветовые литералы вне файла токенов. |
| Пустое сообщение показывало розовую полосу; сообщение об успешной настройке и ссылка входа находились внутри скрываемой формы. | Пустое сообщение скрыто, а статус и ссылка после создания учителя отображаются за пределами формы. | Тест `setMessage`; Chromium проверил завершение первой настройки. |
| Отправка работы использовала `window.confirm`. | Подтверждение открывается общей доступной `<dialog>` с кнопками и управлением с клавиатуры. | UI kit: открыть/закрыть клавишей Escape; axe-core на открытом диалоге. |
| Даты зависели от системного короткого формата; сроки в карточке класса читались как пустые. | Обычные даты имеют формат `дд.мм.гггг чч:мм`, срок показывается текстом с датой и временем; карточка берёт дату из фактического поля API. | Тест утилит с фиксированным часовым поясом; скриншоты кабинета и задания. |
| Метка «Не начато» могла сжиматься, чекбокс растягивался как текстовое поле. | Метки статуса не переносятся, флажки и переключатели имеют компактный размер. | Браузер проверил размер checkbox и отображение статусов в UI kit. |
| Экспорт CSV и JSON занимал две отдельные кнопки. | Оба формата собраны в одном меню «Экспорт». | Проверено раскрытие меню в кабинете учителя и в UI kit. |
| Список классов оставался виден над открытым рабочим местом; на вкладке «Обзор» не перезагружались сводные цифры. | Список скрывается на время открытого класса, заголовок показывает рабочее место; переход на «Обзор» повторно загружает сводку. | Playwright проверил скрытие списка и появление четырёх метрик. |
| В мобильном кабинете таблица требовала горизонтальной прокрутки, навигация оставалась вверху. | Строки таблиц становятся подписанными карточками, внизу появляется навигация, элементы управления имеют высоту не менее 44 px. | 375 px: таблица учеников, карточки заданий и профиля. |
| Ошибки загрузки и отсутствие данных не имели единого визуального поведения. | Добавлены skeleton-загрузка, пустые состояния, сообщение об офлайн-режиме с повтором, повтор загрузки и единый toast. | Компоненты проверяются на UI kit. |
| Подписи вкладки «Работы» не совпадали с фактическим названием «Проверка». | Названия вкладок и статусные подписи собраны в `ui-strings.js`; инструкция также говорит «Проверка». | Поиск по коду и проверка экранов кабинета. |

## Автоматические проверки

- `npm test` — 17/17 тестов пройдены. Включены дата, пустое уведомление, отсутствие нативных popup, отсутствие цветовых литералов в рабочих таблицах стилей кабинета и доступность UI kit только в development.
- Playwright/Chromium: 56 снимков для 14 состояний интерфейса при ширине 1280 и 375 px, в светлой и тёмной теме. Ошибок консоли, сетевых ошибок и горизонтального переполнения не обнаружено.
- axe-core 4.14.0: 10 проверенных состояний; автоматических нарушений на выбранных страницах не найдено.
- Отдельно проверены переходы teacher workspace и проверка отправки задания, поля checkbox, меню экспорта, диалог подтверждения и его закрытие по Escape.
- UI kit отдаётся по `/ui-kit.html` в development и получает `404` в production.

Полный список PNG и машиночитаемые результаты находятся в [browser-check.json](browser-check.json). Проверка выполнена на временной PGlite-базе с тестовыми учителем, учеником, классом и заданием; живые данные не использовались.

Примеры снимков: [кабинет учителя, desktop](teacher-overview-1280-light.png), [ученик и таблица-карточка, mobile](teacher-students-375-light.png), [первая настройка, dark](setup-375-dark.png), [UI kit, mobile dark](ui-kit-375-dark.png).

## Примечания и границы этапа

- `ui-kit.html` намеренно исключён из публичного production allowlist.
- Навигация учителя по отдельным URL, а также замена набора кнопок действий ученика на меню `⋯` относятся к этапу 4; на этом этапе добавлены и проверены общие компоненты.
- Развёртывание на Render/Neon не выполнялось.
