# Этап 3 — проверка редактора CodeMirror 6

Проверка выполнена 10 ноября 2026 года локально на Chromium и временной PGlite-базе. Живые данные учеников не использовались.

## Результат

- `npm test` — **18 из 18 тестов пройдены**.
- `node --check` — все проверенные исходники редактора, кабинетов, серверных маршрутов, урока Bootstrap и сборщика корректны.
- `npm run build:editor` собрал `outputs/assets/vendor/code-editor.js` размером **633,8 КБ** без сжатия.
- `npm run build:vendor` собрал локальный Bootstrap 5.3.8 (`outputs/assets/vendor/bootstrap.min.css`, 232 111 байт) и скопировал его лицензию.
- Найдено и переведено на общий редактор **73 песочницы** из **11 активных уроков**. Один и тот же компонент подключён к работе ученика и просмотру кода учителем.

## Проверка страниц

Playwright открыл все 25 исторических адресов уроков при ширине 1280 и 375 px. Актуальные 11 уроков дополнительно проверены в светлой и тёмной темах на обеих ширинах: всего **72 сочетания маршрута, размера и темы**. Старые адреса корректно перенаправляются в сокращённую программу.

В проверенных состояниях нет горизонтального переполнения страницы, ошибок консоли, внешних запросов и неудачных запросов. Два прерванных запроса `/api/auth/status` возникли при переходе со старого URL на целевой урок; браузер завершил загрузку новой страницы штатно. Они записаны как навигационные отмены, а не как ошибки страницы.

Сохранено **24 скриншота**: уроки 1, 7, 17, 23 и практикумы 16 и 19; каждый — desktop/mobile и light/dark. Например: [урок Bootstrap на телефоне](17-mobile-light.png), [практикум на телефоне](16-mobile-light.png), [Flexbox/Grid в тёмной теме](23-desktop-dark.png).

## Клавиатура и поведение редактора

Автоматизированный сценарий вводит текст через `page.keyboard` в настоящие редакторы. Проверены Emmet HTML-каркас, вложенная карточка, списки, `img`, `a`, `table`; CSS-сокращения `df` и `m10`; автодополнение CSS-свойств; комментарии HTML/CSS; отступ `Shift+Tab`; автозакрытие тегов; раскрытие пустого тега клавишей Enter; мягкие HTML/CSS-подсказки; отключение подсказок, автозакрытия и парных кавычек; размер шрифта и сохранение на сервере; форматирование с отменой; снимок кода перед сбросом и восстановление версии; режим проверки только для чтения с номерами строк.

Также проверено, что предпросмотр не выполняет JavaScript и не обращается к внешним адресам. Урок Bootstrap раньше подключал CSS с CDN; ссылка заменена на локальную копию, поэтому пример и его предпросмотр работают без сети. На мобильной ширине панель действий примера теперь занимает отдельную строку и не сжимает название.
